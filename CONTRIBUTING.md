# Contributing

Contributions are welcome when they remain generic and privacy-safe.

1. Fork the repository and create a focused branch.
2. Use only fictional data in tests, screenshots, and documentation.
3. Run `make test`, `make build`, and `make privacy`.
4. Explain user-visible changes and privacy implications in the pull request.
5. Keep vault formats backward compatible or document a migration.

Do not submit content copied from a private vault or private repository,
including names, correspondence, file paths, project titles, or generated
dashboard data.
